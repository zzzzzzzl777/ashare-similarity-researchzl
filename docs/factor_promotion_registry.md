# 因子晋级登记规则

## 目的

本文用于管理短线 T+1 预测项目的因子生命周期。核心原则是先登记、再验证、再晋级；任何新增因子不能因为概念合理就直接进入正式验收。

因子状态分为：

- `research`：研究候选，只证明想法和可得性，不代表可发布。
- `expanded`：已通过数据闸门，可进入正式探针实验，但尚未通过 75% 验收。
- `passed`：随正式验收 artifact 一起通过，可作为发布前全量拟合输入。
- `blocked`：存在未来函数、披露时点不明、历史不可回放、覆盖过低或实现质量问题。

## 晋级总原则

- 新因子默认进入 `research`。
- 没有披露时点说明的因子不能进入 `expanded`。
- 没有可回放历史快照的因子不能进入 `expanded`。
- 只在训练窗口内完成特征选择、阈值选择和概率校准。
- 测试集通过 75% 准确率、Wilson 下界和 Brier 门禁后，相关配置才可标记为 `passed`。
- 单个因子通过局部消融不等于 passed；passed 是实验配置和 artifact 的状态。

## Research 进入条件

满足任一条件即可登记为 `research`：

- 来自人工研究、外部文档、经验规则或公开数据源的候选信号。
- 已有字段但未证明披露时间。
- 已有实时接口但缺少历史快照。
- 已有计算逻辑但覆盖率、缺失率或稳定性未知。

登记时必须填写：

- 因子名。
- 因子含义。
- 数据源。
- 预测时点是否可见。
- 是否需要分钟线、竞价、涨停池、资金流或文本数据。
- 主要风险：未来函数、幸存者偏差、覆盖不足、口径漂移、免费源不稳定等。

## Research 晋级 Expanded

`research` 因子晋级 `expanded` 必须同时满足：

- 数据源稳定，能在目标交易日回放。
- 披露时间明确，预测时点之前可见。
- 历史缓存或快照可追溯，不能事后补造。
- 缺失率、覆盖率和异常值处理已经记录。
- 通过基础泄露检查，没有使用 T+1 标签或测试集结果构造字段。
- manifest 能记录该因子的来源、版本和快照策略。

不满足以上任一项时，继续留在 `research` 或改为 `blocked`。

## Expanded 晋级 Passed

`expanded` 因子不能单独晋级为 `passed`，必须随完整实验配置一起通过正式验收：

- 高置信 T+1 方向准确率不低于 75%。
- Wilson 95% 下界不低于 75%。
- Brier Score 优于样本正例率常数基线。
- 高置信样本量和覆盖率同时达到预登记要求（AND 门）。
- 测试集未参与因子筛选、阈值选择或校准。
- 实验 manifest 完整，并能复现实验输入。

通过后登记为：

- `passed_config`：通过验收的特征集合、模型、阈值和校准方案。
- `passed_factors`：该配置中实际使用的因子清单。
- `passed_artifact`：对应报告和 artifact 路径。

## 降级和冻结

因子出现以下情况时必须降级或冻结：

- 发现未来函数或披露时点不可证明。
- 历史快照缺失，无法复验当时可见性。
- 免费源接口变更导致口径不可比。
- 覆盖率低到不足以支持正式验收。
- 消融实验显示持续拖累高置信准确率或 Brier。
- 依赖人工主观标注，无法稳定自动化落盘。

降级路径：

- `expanded` 降为 `research`：数据仍可能有用，但尚不满足正式验收。
- `research` 或 `expanded` 改为 `blocked`：存在明确不可接受风险。
- `passed` 冻结：旧 artifact 保留，但不得用于新发布，直到重新验收。

## 当前登记重点

优先推进：

- 真实涨停池：封单、封单金额、首封时间、开板次数、炸板、连板高度。
- 分钟线：尾盘收益、早盘收益、VWAP 偏离、成交分布、日内波动、上涨分钟成交占比。
- 集合竞价：竞价涨幅、竞价量比、竞价成交额、竞价封单、竞价相对强弱。
- 市场温度：涨停家数、炸板率、跌停家数、昨日涨停表现、短线情绪周期。

谨慎推进：

- 题材热度、新闻、股吧情绪、龙虎榜、资金流。
- 这些数据只有在历史快照和披露时点可证明后，才能从 `research` 进入 `expanded`。

暂不晋级：

- 只能事后解释、不能回放的主观事件标签。
- 用未来涨跌幅反推出来的样本过滤或阈值。
- 没有历史覆盖证明的涨停池、竞价或题材字段。

## 登记模板

| 字段 | 说明 |
|---|---|
| factor_id | 稳定英文或拼音标识 |
| factor_name | 中文名称 |
| status | research / expanded / passed / blocked |
| source | 数据源或生成逻辑 |
| visible_at | 预测时点是否可见 |
| snapshot | 是否有历史快照或缓存指纹 |
| coverage | 覆盖率和缺失率 |
| leakage_check | 未来函数检查结论 |
| promotion_reason | 晋级或保留理由 |
| last_run_id | 最近实验编号 |
| decision_owner | 决策人或线程 |

## 当前管理结论

- 默认 `expanded` 只保留已通过数据闸门的稳定因子。
- 新增主观代理因子继续停留在 `research`，除非能证明历史可回放和时点可见。
- 下一轮主要突破口不是继续堆叠日线代理，而是真实涨停池、分钟线和集合竞价数据接入。
- 未达到 75% 验收门禁前，不得把任何实验结论描述为可发布 passed。
