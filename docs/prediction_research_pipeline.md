# 短线预测研究流水线

## 目标

本项目只验收主板短线异动样本：单只股票在对应日期必须处于异动阶段，高换手、高成交/金额、高波动三类条件必须同时成立，并且最近 3 个交易日至少 2 天满足这三类条件。正式方向目标是次日方向准确率达到 75% 以上，并且 Brier Score 优于样本正例率常数基线；50,000 个测试样本是期望规模和报告目标，不作为硬性通过门槛。

## 阶段门禁

1. 数据准备：日线缓存覆盖主板样本，后续分钟、资金流、跨市场和情绪数据必须记录数据源与披露时点。
2. 探针实验：运行 `gpu-prediction-probe`，允许严格阶段样本少于 50,000；验收底线固定为 75% 准确率和 Brier 优于基线，样本量目标单独报告。
3. 验收落盘：每次实验写入 `data/reports/prediction/gpu_probe_latest.json`；只有通过验收才写入 `gpu_probe_passed_latest.json`。
4. 全局拟合：`train-prediction` 必须先读取通过验收的 artifact；没有通过门禁时只能返回 blocked。
5. 发布前检查：保留实验参数、样本区间、特征集、模型、GPU/CPU 阶段、oracle 研究指标和正式验收指标。
6. 概率校准：只能使用训练窗口内切出的验证段拟合校准参数；测试集只能做一次性验收，不允许反向调阈值或校准。

## 训练/验证/测试流程

- 探针阶段必须按时间切分：训练样本使用 `label_date <= train_end`，测试样本使用 `test_start` 之后且 `label_date <= end`。
- 训练窗口内部再切验证集；模型选择、阈值选择、置信区间和概率校准只能使用训练窗口内的验证段。
- 测试集只做一次最终验收，不能参与特征选择、阈值搜索、概率校准或样本筛选。
- 只有测试集通过 75% 准确率和 Brier 门禁后，才允许用冻结后的特征、模型结构、阈值和校准方案做最终全量拟合。

## 当前可用因子路线

P0 只使用现有 OHLCV 日线数据：隔夜收益、日内收益、隔夜/日内拆分、放量反转、MA 偏离、布林位置、冲板失败、影线结构、量价异常、MACD、KDJ、CCI、Williams %R、ADX、涨跌停结构代理、T+1 卖压、累计换手/筹码压力、突破量能、横盘收敛突破和交易日历效应。当前 GPU 探针共 187 个候选特征，其中 163 个为逐股基础特征，24 个为横截面短线情绪特征。

P1 接入免费增量数据：分钟尾盘 30 分钟收益和量比、VWAP 偏离、日内高低点时间、A50/港股/美股隔夜、市场涨停温度、首板成功率。分钟因子计算器已实现尾盘/早盘收益、收盘竞价量比、分时成交分布、量价相关、已实现波动、收益偏度峰度、上午/下午量能倾斜和上涨分钟成交占比；下一步是建立分钟数据批量缓存与日线样本合并。

P2 接入披露时点明确的数据：北向、融资融券、龙虎榜、可转债、期权、新闻和股吧情绪。所有这类因子必须先写数据时点测试，不能用收盘后才公布的数据预测同一交易日。

## 禁止事项

- 不使用测试集标签选择可部署阈值；test oracle 只能放在 research-only 解释中。
- 不在全样本上做特征选择后再回测；标准化、PCA、GA/SHAP 筛选都必须只在训练窗口拟合。
- 不把小样本或降低目标后的结果标成 passed。
- 不用未来 `T+1` 的涨跌幅反过来筛选测试样本；`--min-label-return-pct` 只能做研究，不允许通过正式验收。
- 不把 CPU 阶段描述成全程 GPU。

## 因子候选池管理

- 桌面 `因子探索.md` 作为候选池，不直接等同于可用特征；每个因子先判定数据披露时间，再进入 P0/P1/P2 队列。
- 已落地 P0 日线批次只依赖当日收盘前/收盘时可知 OHLCV，不引入未来标签或测试集结果筛选。
- 分钟、资金流、跨市场和情绪因子必须有独立缓存、来源说明和时点测试；缺少三者之一时不能进入正式验收。
