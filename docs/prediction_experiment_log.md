# 预测实验台账

## 固定验收口径

- 样本：主板短线异动样本，必须同时满足高换手、高成交/金额、高波动。
- 时间：训练区间和测试区间按 `label_date` 隔离，避免次日标签跨入测试期。
- 测试规模：50,000 条是期望规模和报告目标；严格短线异动阶段样本不足时不阻断验收，但必须记录实际样本量。
- 目标：全测试集方向准确率不低于 75%，且 Brier Score 优于样本正例率常数基线。
- 门禁：只有通过 `gpu-prediction-probe` 才能写 `gpu_probe_passed_latest.json`，后续全局拟合必须读取该文件。

## 高置信门槛记录

- 当前正式高置信门槛：验证集选择，测试集只验收；准确率 >= 75%，Brier 优于基线，Wilson 95% 下界 >= 75%，且样本数 >= 10,000 或覆盖率 >= 10%。
- 已把验证高置信最小覆盖率从 5% 提到 10%，避免只挑极窄子集造成发布口径失真。
- 已加入 side-aware confidence band：验证集自动比较 `both`、`long`、`short`，但不使用测试集标签选阈值。

## 当前进行中

- 默认 `expanded` 保持稳定因子集；淘股吧新增的主观/账户/席位类因子只进入 `research` 或暂不落地。
- 当前全量特征缓存：`gpu_probe_features_0096c8197d16afdf.parquet`，301,207 行，覆盖 2,860 只主板股票活跃阶段。
- 当前最佳未通过配置：`expanded`、`max_selected_features=260`、`validation_fraction=0.20`、树模型/MLP/stacking 候选，1000 股抽样高置信准确率 68.406%。

## 下一步

1. 建立分钟因子批量缓存并合并进日线样本：尾盘、早盘、收盘竞价、分时成交分布、已实现波动和上涨分钟成交占比。
2. 接入真实可回放的市场情绪快照：涨停池、炸板池、跌停池、昨日涨停表现，严格按交易日落盘。
3. 评估可程序化的资金流/龙虎榜历史源；没有披露时点和历史快照前不进入正式训练。
4. 若补齐分钟/资金/题材数据后验证集高置信 Wilson 下界仍低于 75%，继续停留研究态，不发布 passed artifact。
