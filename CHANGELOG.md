# Changelog

All notable changes to this project will be documented in this file.

## [0.1.0] - 2026-04-23

### Added

- Local FastAPI web UI with similarity search, export, and status dashboard
- Resumable free-data backfill and maintenance workflow
- `doctor` self-check command
- GitHub governance files, CI, issue/PR templates, architecture and operations docs

### Changed

- Default web startup now prefers local-only binding
- Homepage now distinguishes setup state from query-ready state
- Free-data provider now uses multi-source fallback for stronger daily coverage
